# Matematikai játékok

Mobilon és számítógépen használható, külső függőség nélküli matematikai játékgyűjtemény.

## Játékok

- Kecske–káposzta–farkas
- Éjszakai hídátkelés
- Simon Tatham játékai

## Helyi futtatás

Nyisd meg a gyökérkönyvtárban található `index.html` fájlt.

## GitHub Pages

1. Töltsd fel a könyvtár teljes tartalmát egy GitHub-repositoryba.
2. Nyisd meg: **Settings → Pages**.
3. Válaszd: **Deploy from a branch → main → / (root)**.

## Új játék hozzáadása

1. Hozz létre egy új könyvtárat a `jatekok/` alatt.
2. Tedd bele a játék önálló `index.html` fájlját.
3. Adj hozzá egy új kártyát a gyökérben lévő `index.html` fájlhoz.

Minden útvonal relatív, ezért a gyűjtemény helyben és GitHub Pagesen is működik.
